# Auto Menção Cobrance - Atualizações

Repositório oficial de atualizações para a extensão **Auto Menção Cobrance** do Thunderbird.

## 📋 Sobre

A extensão Auto Menção Cobrance permite mencionar contatos ao compor e-mails e adicioná-los automaticamente como destinatários no Thunderbird.

## 🚀 Como Usar

1. Instale a extensão no Thunderbird
2. A extensão verificará automaticamente por atualizações a cada 24 horas
3. Quando uma atualização estiver disponível, o Thunderbird notificará você
4. Você poderá optar por instalar a atualização imediatamente ou mais tarde
